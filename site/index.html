Honu

Claude Code creates microapps on the fly, right on your macOS desktop.

View on GitHub
  • Describe itTell the turtle what you want, and Claude writes the microapp in moments.
  • Change itType what you want into the bar below a bubble, and every open bubble of it changes.
  • Toss itDrag a bubble to the octopus to remove it. Changed your mind? Click it to get it back.

Get started

Honu needs macOS 26 or newer and Claude Code, signed in with your Claude account. It needs no API key. If you already have Claude Code, the quickest start is to run claude in the repository and ask it to run Honu. Or build it yourself:

git clone https://github.com/ctchuang/honu.git
cd honu
swift run

Xcode is not required: the Command Line Tools are enough.

Status: experimental prototype. Expect breaking changes, and note that there is no protection against prompt injection.
